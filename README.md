# downpour

Rain on a canvas. Move the mouse to change the wind, click for sound.

Plain HTML, CSS and JavaScript, nothing to build. Open `index.html`.

- three layers of drops so there's some depth
- splashes and ripples where the near drops land
- lightning now and then (there's a checkbox if you don't want it)
- wind follows the mouse, or use the slider
- `H` hides the controls
- fewer drops and no lightning if the OS asks for reduced motion

Companion to [wind-animation](https://github.com/samsonidze/wind-animation).

Background photo and rain sound are not in the repo yet; drop a `bg.jpg` and `rain.mp3` next to `index.html`.
