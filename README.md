# downpour

Rain on a canvas. Move the mouse to change the wind, click for sound (rain loop, thunder on each lightning strike).

Plain HTML, CSS and JavaScript, nothing to build. Open `index.html`.

- three layers of drops so there's some depth
- splashes and ripples where the near drops land
- lightning now and then (there's a checkbox if you don't want it)
- wind follows the mouse; untick "Wind follows mouse" to set it with the slider
- `H` hides the controls
- fewer drops and no lightning if the OS asks for reduced motion

Companion to [wind-animation](https://github.com/samsonidze/wind-animation).

Sounds: [rain](https://pixabay.com/users/soundreality/) and [thunderstorm](https://pixabay.com/users/evanaeva/) from Pixabay, re-encoded to mono 96k to keep the repo small.

No background photo in the repo yet; drop a `bg.jpg` next to `index.html` (a night street with some lights works best).
